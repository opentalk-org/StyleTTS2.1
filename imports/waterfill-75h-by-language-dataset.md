# Public TTS dataset collection targets

Generated from `audio-datasets-by-language.md`. The table lists the estimated available duration and the amount to collect from each source. Explicitly requested additions are retained, so some language totals exceed 75 h.

## Subset selection guidance

Prefer collecting the full dataset whenever its available duration is at or below the target. When only a subset is needed, sample by duration across the dataset instead of taking the first files or merely sampling an equal number of rows.

- Cover as many distinct speakers as possible before adding substantially more material from the same speaker. Avoid single-speaker sampling unless the source itself contains only one speaker.

- Balance duration across speakers, and cap dominant speakers before redistributing the remaining target. Preserve gender, age, accent, dialect, and regional variety when metadata is available.

- Spread the subset across recording situations, acoustic conditions, microphones, noise levels, conversational and read speech, domains, emotions, speaking styles, and clip lengths represented by the dataset.

- For datasets with multiple configurations or splits, draw from all suitable training configurations proportionally. Keep evaluation splits untouched when they are needed for comparable evaluation.

- Apply each row's caveats while sampling, including transcript requirements, speech-only filtering, language checks, and duplicate or overlap checks.
